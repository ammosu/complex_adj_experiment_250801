1 基本指標計算

絕對變化 (Absolute Change)
絕對變化 = |當期調整率 - 前期調整率|
最大絕對變化 = max(|Rt - Rt-1|) for t ∈ [247, 251]
變數 說明 範例
Rt 第 t 版本的調整率 R247 = 1.2496
|x| 絕對值函數 |1.4254 - 1.2496| = 0.1758
相對變化 (Relative Change)
相對變化 = |當期調整率 - 前期調整率| / 前期調整率
相對變化 = |Rt - Rt-1| / Rt-1 × 100%
範例計算：
版本 246→247: |1.4254 - 1.2496| / 1.2496 = 0.1758 / 1.2496 = 14.07%

2 變化分析方法

期間變化分析
期間變化序列 = {C246→247, C247→248, C248→249, C249→250, C250→251}
其中 Ci→j = |Rj - Ri| / Ri
指標 計算公式 用途
最大期間變化 max(Ci→j) 識別最劇烈的單期變化
平均期間變化 mean(Ci→j) 評估整體波動程度
變化頻率 count(Ci→j > threshold) 統計顯著變化的期間數

3 穩定性測量

標準差 (Standard Deviation)
σ = √(Σ(Ri - μ)² / (n-1))
其中 μ = (R246 + R247 + ... + R251) / 6
符號 意義 穩定性判斷
σ < 0.05 低標準差 高度穩定
0.05 ≤ σ < 0.1 中標準差 中度波動
σ ≥ 0.1 高標準差 高度波動
變異係數 (Coefficient of Variation)
CV = σ / μ × 100%

變異係數消除了平均水準的影響，更適合比較不同調整率水準的社區穩定性。

4 地理統計分析

縣市層級統計
平均值 = Σ(Ri) / n
中位數 = median(R1, R2, ..., Rn)
範圍 = max(Ri) - min(Ri)
四分位距 = Q3 - Q1
地理集中度計算：
某縣市波動社區比例 = 該縣市極端變化社區數 / 全國極端變化社區總數 × 100%

5 趨勢分析方法

版本間趨勢計算
版本平均調整率 = Σ(Ri,t) / nt
趨勢變化率 = (μt - μt-1) / μt-1 × 100%
指標 計算方式 解釋
線性趨勢 最小平方法回歸 整體上升/下降趨勢
季節性 週期性分解 版本間規律性變化
轉折點 一階差分符號變化 趨勢方向改變的版本

6 資料處理邏輯

缺失值處理
處理原則：
  1. 優先使用 adj 欄位：當 adj 存在時使用 adj，否則使用 ratio
  2. 缺失版本補值：對於完全缺失的版本，使用 1.0 作為預設調整率
  3. 最小資料要求：社區需至少有 2 個版本的資料才納入變化分析
  4. 異常值檢測：調整率超出合理範圍 (0.5-2.0) 的資料會被標記
分析流程
資料載入階段
  1. 讀取 CSV 檔案
  2. 型別轉換與驗證
  3. 缺失值識別
  4. 資料品質檢查
計算階段
  1. 社區資料分組
  2. 版本序列建構
  3. 變化指標計算
  4. 統計指標彙總

實作注意事項

數值精度
  • 調整率保留至小數點後 4 位
  • 變化率以百分比顯示（小數點後 2 位）
  • 統計指標使用雙精度浮點數
效能考量
  • 大型資料集使用向量化運算
  • 預先計算常用統計指標
  • 索引優化加速查詢
